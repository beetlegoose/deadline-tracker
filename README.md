# Deadline Tracker

A simple command-line Java tool for tracking assignment and personal due dates.

## Problem
I constantly lose track of assignment due dates, exam dates, and personal deadlines across different classes and platforms. This tool keeps everything in one local place and helps me quickly see what is most urgent.

## MVP Scope
- Add a task with a due date
- List all tasks sorted by due date
- Mark tasks as complete
- View tasks due in the next 7 days
- Data is saved to a local file

## Future Plans
- Recurring tasks
- Categories / tags
- Priority levels
- Export to CSV
- Better terminal formatting

## Tech Stack
- Java
- Built-in java.time for dates
- Local JSON or text file for storage
- No external libraries or APIs
